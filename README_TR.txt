TIKTOK LIVE PRINTER - SUNUCU TASLAGI

Bu paket, TikTok LIVE Connector kullanan Node.js sunucu + web arayüzü içerir.
Hesap varsayılanı: trvler.999

ÇALIŞTIRMA (Node.js 20+):
1) Bilgisayarda Node.js kur.
2) Bu klasörde terminal aç.
3) npm install
4) npm start
5) Tarayıcıda http://localhost:3000 aç.

ÖNEMLİ:
- TikTok LIVE bağlantısı resmi TikTok API'si değildir; üçüncü taraf/açık kaynak bağlantı kullanır.
- TikTok tarafındaki değişiklikler nedeniyle bağlantı her zaman çalışmayabilir.
- Bu paket henüz internette barındırılmıyor; sürekli çalışması için Node.js destekleyen bir sunucuya deploy edilmelidir.
- Web uygulaması etkinlikleri alıp gösterir. Easy Thermal Print'e paylaşım ile aktarım sağlar.
- Tam otomatik, kullanıcı dokunmadan Bluetooth baskı için Android tarafında desteklenen yazdırma intent'i veya küçük bir Android yardımcı uygulaması gerekir. Easy Thermal Print'in harici intent desteği bu cihazdaki sürümde ayrıca doğrulanmalıdır.
- Bu nedenle otomatik baskı özelliği hazırmış gibi gösterilmez.
